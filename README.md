# isreversi

A work in progress front end to the
[Egaroucid](https://github.com/Nyanyan/Egaroucid)
engine that allows one to play reversi on Android phones.

The front end uses the
[LambdaNative](https://github.com/part-cw/lambdanative)
framework.
